# Getting help

- **Something doesn't work:** open an issue on the repository of the component, with
  the form there. Put in the version, the compositor and what the shell's log says.
- **You want something that isn't there:** open an issue too, and say what you wanted
  to do rather than only how.
- **A question about using or making a plugin:** the READMEs of
  [plugins](https://github.com/twilight-shell/plugins) and
  [plugin-template](https://github.com/twilight-shell/plugin-template) come first, then an
  issue.
- **A security problem:** don't open an issue, see [SECURITY.md](SECURITY.md).
